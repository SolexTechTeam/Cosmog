Before implementing significant work: Plan first, then run /improve to generate implementation plan, then implement.
Before any PR: run /simplify then /code-review and fix all findings before opening.

**Why:** User wants structured, reviewed work — no cowboy coding. Plans ensure alignment, /improve generates agent-ready tasks, pre-PR reviews catch quality issues before they hit the remote.

**How to apply:** Every non-trivial task starts with planning. Every PR goes through both review skills. No exceptions.
